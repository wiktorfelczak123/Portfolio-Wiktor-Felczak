# Portfolio projektów Wiktora Felczaka

Przykładowe projekty pokazujące praktyczne podejście do wdrożeń systemów B2B, testów UAT, wsparcia aplikacji, analizy zgłoszeń i porządkowania wiedzy.

## Projekty

| Projekt | Co pokazuje | Materiały |
|---|---|---|
| Zestaw API i UAT | Testowanie integracji, analiza odpowiedzi HTTP i dokumentowanie przypadków | [README](projects/01-api-uat-kit/README.md) |
| Studium wdrożenia | Harmonogram, zależności, ryzyka, UAT, szkolenie i gotowość do uruchomienia | [README](projects/02-implementation-case-study/README.md) |
| Analiza zgłoszeń | SQL, Excel, syntetyczne dane, wskaźniki i trendy | [README](projects/03-ticket-analysis/README.md) · [arkusz Excel](projects/03-ticket-analysis/ticket-analysis.xlsx) |
| Baza wiedzy i test | Organizowanie źródeł, projektowanie pytań i śledzenie ich do materiałów | [README](projects/04-knowledge-check-demo/README.md) |

## Ważne

Projekty są demonstracyjne. Dane w analizie zgłoszeń są syntetyczne, a opis wdrożenia i materiały bazy wiedzy są fikcyjne. Repozytorium nie zawiera danych klientów, materiałów pracodawcy ani informacji poufnych. Przykładowy test wiedzy w projekcie 4 został przygotowany na podstawie dołączonych fikcyjnych źródeł; nie jest to eksport z NotebookLM.

## Jak zacząć

- Projekt API: Python 3, Postman; instrukcja uruchomienia lokalnego mock API znajduje się w jego README.
- Studium wdrożenia: otwórz dokument Markdown z planem i checklistami.
- Analiza zgłoszeń: arkusz Excel zawiera podsumowanie i dane źródłowe; zapytania SQL są w osobnym pliku.
- Baza wiedzy: zacznij od README projektu, a następnie porównaj pytania z dołączonymi źródłami.
