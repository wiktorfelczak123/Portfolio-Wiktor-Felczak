# Materiał archiwalny — wcześniejsza demonstracja

Ten plik zawierał fikcyjny przykład utworzony na potrzeby dawnej demonstracji. Nie jest dokumentem pracodawcy, nie opisuje procedury używanej w pracy i nie stanowi dowodu doświadczenia zawodowego.

Publiczna prezentacja doświadczenia znajduje się w pliku README tego projektu. Oryginalne źródła firmowe nie są publikowane.
