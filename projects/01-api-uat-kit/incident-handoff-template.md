# Karta przekazania problemu dostawcy

Publiczny szablon opracowany na podstawie doświadczenia w koordynacji diagnozy. Wypełniaj go informacjami zatwierdzonymi do przekazania; nie dołączaj haseł, tokenów, danych osobowych ani niezanonimizowanych zrzutów.

## Zgłoszenie

- **System lub funkcja:** [nazwa uogólniona]
- **Data i przedział czasu:** [uzgodniony format]
- **Zakres wpływu:** [użytkownicy / proces / ograniczenie]
- **Objaw:** [co użytkownik widzi lub czego nie może wykonać]
- **Oczekiwane zachowanie:** [opis]
- **Kroki odtworzenia:** [1, 2, 3]

## Sprawdzenia

- [ ] Ustalono, czy problem dotyczy jednej osoby, wielu użytkowników czy całego procesu.
- [ ] Zapisano czas zdarzenia i zmianę, po której problem zauważono.
- [ ] Zebrano wynik dostępnych sprawdzeń i osobę lub dostawcę odpowiedzialnego za następny krok.
- [ ] Jeśli sprawdzano logi aplikacji, usunięto z przekazywanego wyciągu dane wrażliwe i identyfikujące.
- [ ] Nie wykonywano zmian infrastruktury bez właściciela i uzgodnionego zakresu.

- **Właściciel następnego kroku:** [rola / zespół]
